## Know your motivation
1. Contribute for skill enhancement, bug fixes, assisting others, or demonstrating capabilities.   
2. Have defined goals because they will improve your productivity and teamwork.
## Be Kind & Respectful
1. Use courteous and supportive language with others.
2. Recognize contributions and celebrate successes.
3. Do not make assumptions about contributors' knowledge, experience, or background.
## Make Meaningful Contributions
1. Work on useful fixes (bugs, documentation enhancements).
2. Do not make trivial changes like correcting punctuations.
3. Read and adhere to project style guides before making changes.
4. Read the documentation thoroughly.
## Speak Clearly
1. Keep the topic on track and do not make off-topic remarks.
2. Resolve a single issue per pull request so that they're easy to review and understand.
3. Utilize forums or chat for common inquiries rather than github issues.
## Be Patient & Professional
1. Numerous contributors contribute voluntarily—wait before sending follow-up remarks.
2. If unable to perform a task, report and seek reassignment.
